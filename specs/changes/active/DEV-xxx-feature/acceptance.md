# 验收计划

## 验收范围

说明本次验收覆盖的用户目标、系统边界和明确不覆盖的内容。

## 自动化场景

每个场景使用稳定 ID，并按 Given / When / Then 描述。

| 场景 ID | 关联需求 | 场景 | 测试位置 |
| --- | --- | --- | --- |
| `<场景 ID>` | `<需求 ID>` | Given `<前提>`，When `<动作>`，Then `<可验证结果>`。 | `<测试用例>` |

## 人工或 live 场景

仅在自动化无法证明时使用，并记录环境、操作者、时间、版本和证据位置。

## 非功能门槛

写明测量环境、样本量、时间窗口、阈值和失败判据。

## 通过条件

列出将本变更判定为完成所需的全部证据，以及 `Partial`、`Blocked` 或失败时的处理方式。
