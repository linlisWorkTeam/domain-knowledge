# ADR-008：回滚能力显式降级

- 状态：Accepted
- 日期：2026-09-02

## 背景

早期模型同时声明了 `ROLLBACK` Gate 结果、`ROLLING_BACK` 状态和工作流回滚节点，但没有定义可回滚版本、兼容性校验、操作权限或失败后的发布语义。实际 `decideGate` 从未产生 `ROLLBACK`，工作流节点因此不可达。

## 决策

当前 Gate 只公开 `PASS`、`ITERATE` 和 `STOPPED`。LangGraph 不注册不可达的回滚节点，应用服务也不把 Gate 结果映射到自动回滚。

为保持已持久化数据和状态机迁移兼容，`ROLLING_BACK` 及现有 `TRANSITIONS` 暂时保留为预留状态，但不宣传为已实现能力。未来只有在规范先定义目标版本选择、兼容性门禁、操作权限、审计事件和失败恢复后，才能通过新的 ADR 恢复自动回滚结果。

## 后果

类型、图结构和产品文档不再暴露幻影能力；现有确定性 Gate 输出语义与状态机迁移表均不改变。直接进入预留状态不等于完成回滚，也不得产生发布或 `VERIFIED` 状态。
