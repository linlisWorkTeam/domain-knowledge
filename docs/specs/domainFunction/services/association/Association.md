# 事实关联设计

代码位置：[AssociationDomainService.ts](../../../../../src/domain/services/association/AssociationDomainService.ts)。

本服务位于 `services/association`，向 Application 提供关联能力。DocWorkerAgent 属于内部源码分析角色，其事实工件用于 DocGen；本服务当前不调用 DocWorker，也不重复角色的 Prompt、模型步骤或源码引用校验。

输入包含正文、来源、候选目标和显式注入的提取与映射策略。领域服务先校验正文与来源非空，提取事实并检查 factId 非空且唯一，再将事实映射到候选目标。

每条关联必须引用已提取的事实和已提供的目标，confidence 在 0..1 范围，reason 非空。失败直接拒绝结果；成功返回事实和关联的数据副本。Application 协调调用与持久化，本模块不访问数据库或模型 SDK。

当前能力是已有策略的领域校验边界，不表示已实现 SearchAgent 或检索链。调用入口见 [Application 设计](../../../application/Application.md)，修改步骤见 [开发指南](../../../../Development.md)。

工作台关联阶段使用冻结卡片版本建立可恢复 JSON 关系索引。首种规则为同仓库、同源码版本卡片正文对另一知识单元公开符号的明确引用；记录引用行、片段、双方版本和正文摘要。领域规则不把标签重合解释为语义依赖，也不保证关联卡片可直接替代当前卡片。没有命中返回空列表；没有外部材料明确标记仅库内关联。指定材料读取已接入不可变快照；外部关系和任务选材仍待接线，不主动搜索。

ASSOCIATE 与其他阶段共用持久化任务、取消和检查点。启动冻结输入，执行前检查当前版本与索引摘要；关系索引保存在 CAS，SQLite 任务保存引用。读取候选时排除失效版本，返回实际关联方向、引用证据及适用条件；正文或元数据变化要求重新建立关联，不沿旧关系静默推荐。

## 指定外部材料快照

外部材料由「来源」已有 FILE/HTTPS 登记项明确选取。Application 捕获固定修订的原始字节、可读正文和适用条件；Infrastructure 沿用来源根目录、HTTPS 主机及地址限制，不发现新链接、不主动搜索。来源读取失败或内容漂移时拒绝捕获，不伪造材料。网页正文去除脚本、样式与标记，保留原始工件供审计；仅接收有界 UTF-8 文本，不解释二进制文档。

材料标识绑定来源、固定修订、正文转换契约和适用条件，SQLite 保存不可变记录，CAS 保存原文与正文。重复捕获复用同一材料；来源改变后需先确认新修订，再捕获新材料。材料快照不等于卡片，也不获得 VERIFIED 状态。后续关联任务冻结明确材料标识，关系记录引用来源位置及适用条件；不把符号提及认定为行为等价。
