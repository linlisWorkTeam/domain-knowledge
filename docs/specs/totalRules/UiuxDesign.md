# Console 与网站交互设计

代码位置：[web/index.html](../../../web/index.html)、[web/App.js](../../../web/App.js)、[web/Styles.css](../../../web/Styles.css)、[site/index.html](../../../site/index.html)、[src/interfaces/runner/ConsoleReadModel.ts](../../../src/interfaces/runner/ConsoleReadModel.ts)。


## 用户任务与信息结构

生产导航唯一有效版本为“操作中心、飞轮批次、知识、工作流图、评测、来源、Agent 设置”。`web/prototype/` 是历史原型参考，当前运行界面由 web 根文件实现；网站 site 负责介绍项目和指向工程入口。

批次列表回答状态和阻塞原因，详情展示节点、轮次、尝试、证据、Gate 和发布回执。知识页区别 CANDIDATE、LOW_CONFIDENCE、VERIFIED 和 SUPERSEDED；工作流图只读，不能拖拽改连接或逐节点推进。操作中心展示需要处理的事实，普通自动迭代不要求人工确认每一步。

## 交互状态

| 页面行为 | 读取事实 | 用户动作及结果 |
| --- | --- | --- |
| 启动与观察 | Run、节点投影、事件与进度 | 提交场景；取消传播到执行器；恢复须通过兼容检查 |
| 待处理事项 | 类型、原因、revision、allowedActions | ACKNOWLEDGE / RESOLVE 等合法动作，冲突刷新后处理 |
| 知识与评测 | 来源、Diff、规则修订、证据引用 | 只读审查，反馈或重建新批次，不直接发布 |
| Agent 设置 | 固定职责和模型可用性 | 只允许编辑 promptAddon；模型设置由服务端保存并验证 |

信息缺失显示“暂无数据”或不可用，不能显示虚构 0 分、百分比或 ETA。执行阶段与业务状态分开呈现，错误摘要说明原因和下一步。

可恢复执行失败显示“执行失败”，详情保留“业务阶段：生成中”等历史阶段并展示安全错误码、失败节点及恢复条件；不计入运行中，不提供取消。列表支持独立“执行失败”筛选；窄屏保留状态文字，避免仅靠颜色或图标判断结果。只有当前活动执行显示运行阶段及取消；恢复需要治理认证，成功或拒绝后刷新执行事实并保留原预算。已取消执行中的历史 RUNNING 节点显示“历史节点状态：运行中”，不代表仍有活动进程。

模型设置在验证按钮旁明确说明会发送一次最多 64 输出 token 的最小生成、可能产生少量费用且不会自动重试。验证中禁用重复点击，分别显示模型列表和最小生成检查结果；旧的仅列表验证要求重新验证，不自动发送请求。API Key 和治理令牌不进入浏览器持久化或截图证据。针对性受控回归见 RunExecutionConsole 和 Console 浏览器用例。

## 视觉与可访问性

Console 与网站分别保存主题偏好，支持浅色/深色及系统初始主题。中文术语保持一致，状态同时使用文字与颜色，键盘可操作、焦点可见，200% 缩放不遮挡关键读取路径；页面资源同源提供。证据细节按需展开，不将内部数据库、SDK 会话或凭据配置细节放进普通业务流程。

接口以 [Preview HTTP API 规范](../interfaces/HttpApi.md)为准；本设计不复制路由实现。

## 阅读与视觉重构（2026-09）

本次以已发布 Console 为基线，保持七个导航入口、主题偏好、API 权限和真实数据口径。视觉采用低饱和绿色、统一中性色和 12px 起的辅助字号；正文 15px、宽阅读面板，状态使用文字与颜色，按钮有明确焦点。复用原生 HTML/CSS，不增加 UI 框架、远程字体或持续动画，适应低资源 Linux 服务及离线安装。

知识详情首先呈现状态和正文，版本、来源、摘要放入可展开证据区。`web/KnowledgeMarkdown.js` 仅解释标题、段落、粗体、行内代码、围栏代码、平面列表、引用和简单表格；HTML 一律转义，模型给出的图片和链接不转为活动资源。不支持的语法保留文本，可查看或复制完整 Markdown 原文。文章目录使用内部生成 ID，保留 Escape 关闭和返回原卡片焦点。正文不再置于固定高度的嵌套滚动区，横向表格可键盘滚动。

操作中心分类按钮必须实际筛选治理记录；无匹配项显示空状态，不宣称仍待处理的事项已全部解决。首页只展示服务端可证明进度，移除固定百分比和推测的已完成步骤。知识列表的状态、标题、摘要与元数据形成阅读层级，列表筛选及版本比较保持可用。

验收覆盖两种主题、1440px 桌面、390px 窄屏、200% 等效布局、真实知识正文、目录、原文、筛选与键盘焦点；运行现有 Console 行为回归及 Markdown 注入测试。视觉证据使用明确标注的当前真实数据，不混作模型或安装包的新验收结果。技能来源为 taste-skill 的 redesign audit；该技能不负责数据控制台，不套用其中的营销页 Hero、动效或图片规则。

## 界面文案审阅（2026-09-10）

先阅读实际页面截图，再用页面文本和源码定位对应文案。界面面向查看运行与知识结果的使用者：说明优先回答“是什么、能做什么”，不把持久化、投影、运行聚合等实现术语直接用作帮助文字。按钮使用明确动词，如“保存配置”“查看发布设置”；最近动态标题和时间各出现一次。

例如“查看真实节点投影”改为“查看各角色的执行情况”，“无分母时不计算分数”改为“数据不足，暂不评分”。进度、缺失值、评测计数及指标计算不随文案改写；三轮内收敛指标以“三轮内通过率”展示，详细口径仍可查看。API Key、token、版本、原始错误码、角色契约和知识正文保持保真，不在展示层改写审计材料。AI-flavor-remover 用于界面文案审阅，不以检测器分数验收，不添加拟人化闲话。

验收沿用 Console 行为与截图回归，只更新改字导致的视觉基准，保留原有像素阈值；另对当前本地实例截图复核长文案、禁用状态和窄屏换行。没有新增运行依赖、模型调用或后台任务。

用户确认本部署免登录：`WP_KNOWLEDGE_NO_LOGIN=1` 使本地与远程访问都可编辑，页面根据 `directEditing` 自动启用操作，不再展示服务端写入关闭说明。不开此选项时，直接回环访问且无令牌也可编辑；已有远程 Bearer 配置保留兼容。免登录明确允许持有公网链接者操作，不代表账户权限系统；仍拒绝跨站浏览器写入，并保留目录范围、模型端点校验和密钥脱敏。


## 卡片目录与执行事实

知识页默认使用 `/api/v1/cards` 展示当前卡片；历史版本从详情展开进入，保留正文、版本比较、来源和门禁访问。搜索明确针对名称、用途和关键词，避免宣称摘要搜索已覆盖正文。无令牌且 `directEditing=true` 时证据下载使用匿名请求。工作流优先读取 `executionStatus`；缺失或读取失败显示未知，缺执行事实的节点不计入等待或未开始。

源码分析、模块选择、构建参数表单、五阶段操作入口、用例失败详情和库内关系回退已接通。规范化源码诊断已接通，自动知识修订已接通，最终发布仍待交付；不能以阶段完成代替完整产品验收。当前网站在完整验收后更新，不改写 v0.2.0。


知识页提供可展开的“知识索引与试检索”：更新索引、读取进度和新增/更新/复用/失败数量、取消/恢复、失败卡片入口、摘要命中原因和 YAML 预览。进入知识页不自动构建；只有用户操作启动任务。观察失败重试同一任务，不能重复启动。窄屏表单纵向排列，YAML 只在自身区域滚动；所有模型内容转义。默认卡片列表与原有版本详情保留。


操作中心顶部提供仓库目录和源码版本输入，以及“分析仓库”。结果展示固定提交、构建配置文件类型、工具版本和模块候选；不要求场景 JSON，不自动启动生成。输入期间刷新保存值和光标，窄屏纵向排列。选择支持的模块并保存固定项目输入后，可单独生成知识或一键执行全部阶段。顶部布局变更更新对应截图基线，保留原几何断言和1%阈值。

仓库分析结果提供模块复选框与构建参数表单，默认选择支持范围；当前页面最多显示200模块，保存不包含未展示的模块。参数采用编译器/标准选择及逐行目录/定义，无需场景JSON。保存显示明确输入版本，修改后标为未保存；失败保留分析，不宣称已生成知识。


操作中心的项目输入保存后提供「生成知识库」及可选入口路径、类范围和逐行符号选择，不要求场景JSON。任务展示固定提交、当前符号、已完成卡片、累计用量与明确错误；逐卡产物可阅读，评测单独标记为待执行。支持取消和同输入恢复，已完成卡片引导至知识页面建立索引。当前此入口只实现C/C++生成，TypeScript保留现有模块回归；未接通的飞轮、评测和关联不显示为成功。


生成完成后提供「执行代码重建」，展示冻结知识版本数、输入快照、累计调用、接口比较、生成代码与比较工件下载，支持取消、重启后读取和同输入恢复。可展开规范化函数差异，查看两侧变更片段、行号、词法相似度和控制关键词计数，不能将其当成语义等价。未唯一定位或预算不足明确列出；自动知识修订从可信行为失败进入；FLYWHEEL的执行成功不代表完整飞轮或发布验证通过。

重建后提供「执行评测」：显示候选参考拒绝或可信行为结果、复用/新增数量、逐用例输入调用、预期/实际表格与章节版本链接。完整报告按工件加载，不把JSON作为唯一阅读入口。错误候选提供「重新生成候选测试」，保留累计预算；参考依赖错误先停止、不调用TestGen。任务成功、行为成功与发布资格分别表达；刷新可读取相同任务和失败报告。

知识索引完成后可独立「建立关联」，显示冻结卡片数、关系数、状态、取消/恢复和关系索引下载。卡片详情提供「当前卡片不适用」读取已有关系，展示对应版本入口、实际引用行和片段、候选适用条件；明确尚未证明可替代性。无关系、过期关系、读取失败分别显示真实状态。可显式选择固定外部材料，另列材料引用、行号、来源修订及适用条件，可下载原文和引用正文；不主动联网搜索。

生成代码未通过编译检查时，代码与诊断可下载；「恢复重建」在原任务内修复已证明存在编译问题的生成代码，累计用量保留。资源暂停仍复用原生成代码，不能把暂停显示为模型质量拒绝。

原生失败用例详情展示隔离编译/运行stderr，最多预览8192字符，完整证据仍可下载。内容按纯文本转义，不把参考诊断交给Code或当作知识修订依据。

历史可信测试与新参考冲突时显示「历史可信门禁与当前参考冲突」及原始输入/预期/实际；任务PAUSED并提示检查源码和环境，恢复不会进入模型候选替换。公开接口变化或门禁容量超限显示明确暂停原因，不静默删除已有测试。

操作中心保存项目输入后显示「一键执行全部」，与独立生成共用接口范围表单。五阶段列表展示真实子任务状态、输入版本、卡片、索引计数、接口匹配、评测通过数及关系数；失败阶段提供已保存证据下载。「取消全部」传播至当前子任务，「恢复全部」使用原inputDigest。刷新后读取持久化协调任务；未启动阶段明确标注，未知状态不猜测为等待。流程完成不等于发布通过。

来源详情增加「外部关联材料」：填写适用条件后捕获固定修订，查看正文和材料标识；错误在原操作位置展示。只捕获用户选择的登记来源，不自动搜索网页。快照与已验证知识状态分开。

评测结果可点击「查看修订依据」，按需校验并展示当前章节和关联失败用例。历史或失配章节、无行为观察的编译/运行故障明确列入未解决项。候选不等于已证明知识错误；查询入口只读；存在当前章节候选时可另行「执行知识修订」。修订面板显示原因、前后正文、下载、取消/恢复、质量拒绝或未解决项。索引成功且没有阻塞项后可「重建修订版本」，明确使用新版本集合。自动多轮推进见 v4 迭代记录。


### 自动迭代的操作反馈

v4 一键流程展示当前实际执行任务（含知识修订）与累计用量，并保存每轮的冻结输入版本、代码/评测/修订编号和通过数量。展开轮次后可选择「查看第 N 轮评测」，联动原有重建、用例与修订面板；历史失败不因后续成功而消失。当前阶段摘要只引用当前子任务，不能误选第一轮历史结果。

知识修订质量拒绝、证据不足、连续无行为进展均明确展示原因与恢复入口。Review 判断知识无需修改时，独立修订面板提供「重新生成代码」，保留原版本并绑定失败评测。旧契约只读；阶段完成仍与知识发布状态分开显示。


v5 启动冻结修订后的当前版本时，流程面板显示“本流程使用启动时冻结的修订版本，原生成产物保留”。第一轮的输入版本按钮对应该集合；生成阶段仍展示原始卡片证据。跨源码快照或血缘不一致时显示具体原因，不能暗中替换或回写旧版本。


当前执行契约为 pipeline-v9 / knowledge-revision-v5。旧实验修订仅可读取；当前 Review 的授权章节在模型调用前固定，模型提出未授权意见时明确失败，不显示为已经获准修订。已完成卡片仍保留，可在后续新流程选用当前版本。

评测成功执行后，无论行为用例是否通过，都可「复核全部卡片来源」。面板逐卡展示冻结版本、来源匹配／矛盾／未解决结果及意见下载，提供取消和同契约恢复。来源复核不充当普通行为评测，不覆盖原报告，也不授予发布资格。刷新页面时两类任务按 operation 分开恢复。

整卡复核存在明确矛盾时显示「按来源意见修订」，复用修订正文对照、意见下载、取消/恢复和增量索引结果。来源修订面板与行为修订面板独立绑定各自任务，按钮事件限定在所属面板。修订后「重建修订版本」使用新版本集合；来源意见本身不作为行为失败重试依据。

一键 v10 在迭代记录中显示本轮整卡来源复核状态和查看入口，当前任务区区分行为修订、来源修订与逐章来源复核。行为通过但来源矛盾时继续相应修订；未知来源和连续无来源进展分别显示暂停原因。来源 v2 显示当前H2进度和每章意见下载，旧v1仅只读展示，不显示恢复按钮。

重建完成后的评测面板提供“固定用例评测”折叠区：按模块选择已准备的声明式用例文件，启动独立固定评测，查看参考/生成实际值与预期的表格、失败诊断和报告下载。无需编辑场景JSON；取消/同输入恢复保留逐案记录。参考拒绝与生成失败分别展示，完成不等于知识已发布。

编译数据库候选在分析结果的折叠区列出源码、来源记录、提取参数和问题；有未支持项时禁用应用按钮。应用只填充现有构建表单并使已保存项目输入失效，仍由保存动作冻结输入。明确公共参数适用于全部所选模块。

来源章节沿用既有矛盾时，显示“沿用同一正文已有的来源矛盾，尚待修订”及原任务身份；不能显示为新模型调用或将后续PASS覆盖成已验证。

一键流程提供按模块选择固定用例文件的折叠区，选用时应覆盖全部所选模块。迭代记录显示固定子任务状态、通过数和下载入口，原生评测详情复用独立固定面板。未提供固定用例时明确显示尚不具备最终验证发布条件。

来源复核详情展示冻结的单次上限（新策略600秒，旧输入180秒），说明取消和总预算仍有效；不能把延长期限表示为放宽质量门禁。

重建详情增加“验证与本地发布”：用户明确选择绑定当前重建的可信评测、固定评测以及绑定所选可信评测的来源复核。历史任务分页读取，切换重建忽略旧请求结果。提交只传任务编号，服务端验证冻结证据。按当前完整版本集合展示发布，COMMITTED 显示已验证并发布，PREPARED 提供恢复；文件清单提供匿名部署可用的受限下载。发布失败保留原阶段产物，刷新重新读取审计状态。独立入口与一键流程最终发布已接通；桌面/窄屏浏览器验收仍待完成。

一键流程v15读取服务端publicationVerified和publication，提交成功显示“已验证并发布”以及受限卡片/清单下载；未提交明确显示尚未完成验证发布，旧v14只读。原生验收脚本v4分别对一键和分步调用同一发布用例，仅在提交及导出文件校验通过后记录VERIFIED_PUBLISHED和publicationId。脚本能力不等于真实验收结果。

仓库分析构建表单提供“参数范围”：项目默认或所选模块。首次编辑模块复制当前默认值，可独立调整编译器、标准、包含目录与宏，或恢复继承；取消模块选择移除其覆盖。保存的模块参数同样用于生成、Code、评测及发布校验，不要求场景JSON。Make/CMake动态配置提取与实际模块不同参数编译/浏览器验收仍需单独验证。

操作中心提供已保存仓库/源码版本选择，可载入原snapshot继续任务；读取失败保留当前项目。切换项目清空旧生成/重建/流程的页面状态及轮询，不取消服务器任务。生成和重建历史按snapshot/阶段分页读取，重建还核对完整卡片版本集合；旧任务仍可在批次中查看。修改参数需重新分析并保存新输入。

生成页面在接口编译失败时按模块显示最近诊断的明确缺失头文件/链接库，并提供绑定当前阶段的完整报告下载。无法识别的错误仍保留报告，不虚构缺项或包名；修改构建参数后保存新项目输入，原任务与证据保留。环境工具列表包括可选clang++。

发布文件下载保留服务端清单中的稳定卡片.md、manifest.json、evidence.json文件名；前端不再统一改名为evaluation-evidence。非法文件名仅使用安全默认名，旧阶段/评测下载名保持原行为。完整Console发布用例覆盖历史快照选择、四任务证据提交、刷新后状态、匿名下载及桌面/窄屏截图；新增用例需实际运行后才能声称浏览器验收通过。

来源复核的未知章节可通过“补充验证用例”启动显式补证任务：页面使用选中来源记录与其原评测的重建编号，不要求输入JSON；启动后进入现有评测面板展示进度、复用/新增数量、失败用例与取消/恢复。来源未完成或旧契约不显示该入口，新增测试通过仍需再次来源复核，不显示已发布。
