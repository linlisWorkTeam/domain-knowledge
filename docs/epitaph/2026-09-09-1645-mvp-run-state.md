# 失败执行状态与浏览器验证交接

用户已授权按失败分析优先级修复；本任务在独立工作树 `/tmp/domain-knowledge-mvp-product`、分支 `fix/mvp-run-state` 从 cff8fc1 开始，bootstrap READY。只调用受控测试，无真实模型请求，未修改原源码、安装包、真实验收账本或发布。历史 3/3 次真实验收预算已耗尽，仍以 1225 交接为准。

新增只读 RunExecutionPresentation，经 Orchestrator 和 HTTP 列表/详情返回 executionStatus、executionFailure、recovery、isActive 和 canCancel。保留领域业务状态；执行 FAILED、业务 GENERATING 的可恢复失败明确显示执行失败，不再计入运行中。status 查询保留业务语义，executionStatus 独立筛选。兼容性调用 RunConfiguration.assertCompatible，跟随当前角色执行版本，不硬编码；缺失/耗尽预算、旧版本和缺节点均不可恢复。最终恢复命令继续执行授权与预算检查，拒绝原因有明确 409；历史 RUNNING 节点不改写，界面标为历史节点状态。

Console 更新活动统计、筛选、详情、取消和恢复；未知执行不可假定活动。失败摘要只输出安全错误码与节点，不回传原始服务异常。Provider UI 对接 validation 的两阶段探针，提示主动验证将发一次最多 64 输出 token 的最小生成、可能费用、不自动重试；分别展示 modelList/generation checks 和旧验证需重验原因。HTTP 验证在客户端断连时传递 AbortSignal。依赖来自 validation 的 7c2beab 和 552ca1a；主整合这些原提交后只需摘取产品组最终提交。
